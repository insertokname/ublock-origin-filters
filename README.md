# ublock-origin-filters

a bunch of random tweaks to make the web more usable. This isn't really inteded for general use since there is a bunch of shit like:

- removal of all spotify frontpage sections except playlists
- huge popup when opening instagram.com

but also includes some quality of life stuff like

- making brainly.ro usable

if you are interested in any of these checkout [filters.txt](filters.txt) and pick and choose your filters.

## Install instructions (for when i forget how to)

go to ublock origin settings

go to the tab "filter list" and at the very bottom add this url `https://raw.githubusercontent.com/insertokname/ublock-origin-filters/refs/heads/main/filters.txt`

this will get most basic filters but for advanced stuff you need to add the custom resource

go to the settings tab, click "i am advanced user" click on the settings icon next to that and at the bottom of the file set

```
userResourcesLocation https://raw.githubusercontent.com/insertokname/ublock-origin-filters/refs/heads/main/javascript-resources.txt
```

that's about it
